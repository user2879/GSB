这台工作机是新划拨的，项目根目录下除了空文件夹之外没有任何内容，代码、配置、账本与本地样本都需随首个版本一并落地到 Linux（WSL Ubuntu）环境。业务对象是本地确定性合成的指令样本流：每条样本含样本标识、指令模板标识、槽位填充值列表、期望回答模板标识与来源分片；指令模板以修订链形式演进，每个模板修订显式引用父修订并可修改模板文本、槽位集合与约束规则，样本按批次滚动到达并会被逐条替换或删除。构造管线需完成模板解析、槽位校验、指令与回答的确定性渲染、样本去重与配比统计，并把构造结论写入持久化账本；使用者会反复编辑模板修订链、槽位约束、去重阈值与定点计量口径，要求每次编辑后只重算真正受影响的样本、渲染产物与配比统计，并在进程被强制终止后从快照恢复出与全量运行一致的结论。

任务环境与准备：
在 Linux（WSL Ubuntu）新建空工作目录作为项目根目录。
安装 Python 3.11 与 venv：使用发行版自带 python3 与 python3-venv 包，创建并激活虚拟环境。
在虚拟环境中安装依赖：pip install numpy pyyaml；Tkinter 使用发行版 python3-tk 包安装，并在无显示环境下用 Xvfb 验证界面可构建。
运行前由示例脚本生成全部本地确定性样本（模板修订链、指令样本流、配置与注入清单），不依赖任何外部账号或网络资源。

业务要求：
1. 实现模板修订链、指令样本流、构造配置与命令流的加载校验层：校验模板标识与修订号唯一、每个修订显式引用存在的父修订且修订链无环、样本标识唯一、样本引用的模板修订存在于链中、槽位填充值与模板声明的槽位集合一一对应、去重阈值为 0 至 1000 的千分比整数、定点小数位宽与量化档位在允许枚举内，非法时输出 E_TEMPLATE_INVALID、E_SAMPLE_INVALID 等业务码并进入失败清单而不中断其余样本。
2. 实现模板解析与确定性渲染阶段：按修订链逐级合成模板的有效槽位集合与约束规则，后出现的修订可覆盖或追加槽位但必须记录覆盖来源与生效修订号；渲染指令与回答时按槽位名升序填充，同一槽位名重复填充按固定优先级决断并记录被抑制值，相同输入与模板修订下多次渲染必须逐字符一致，渲染产物携带由模板修订链指纹、样本内容指纹与槽位值集合派生的渲染摘要。
3. 实现样本级定点质量打分与去重簇账本：按槽位填充完整度、模板覆盖率与回答长度衰减在定点整数域合成样本质量分并记录量化步长与残差，随后以子词集合相似度阈值做近重复去重，簇内保留定点质量分最高者、同分按样本标识字典序决断，被剔除样本须记录保留样本标识与相似度值；相似度恰等于阈值时按固定规则决断并标记边界对。
4. 实现基于内容指纹的模板级与样本级精确失效判定与复用账本：为模板有效槽位集合、每条样本渲染产物、质量分、去重簇归属与配比统计各阶段产物计算由上游内容指纹、模板修订链指纹、参数指纹与量化档位派生的缓存键，并记录每条样本引用的模板修订与每个统计结果引用的样本集合；编辑某一模板修订、替换单条样本或调整去重阈值时，只使引用它的样本渲染、质量分、簇账本与配比统计失效，未受影响样本必须直接复用持久化产物并记录复用命中依据。
5. 保证任意编辑命令序列后增量运行与从空白全量构建逐字段一致：施加包含新增样本批、单条样本替换与删除、模板修订增删与回滚、槽位约束修改、去重阈值调整与量化档位切换的编辑序列，每次稳定后增量运行得到的逐样本渲染文本与渲染摘要、质量分与残差、去重簇归属与被剔除清单顺序、配比统计、缓存键、复用与重算清单以及失败清单顺序，均须与按相同最终样本集合和配置一次性全量运行的结果逐字段一致。
6. 实现单批渲染点数预算与单来源分片配额约束下的并发调度：样本通过线程池并发执行渲染与质量打分，最大并发数取自配置且不得超过；调度器按来源分片标识与样本标识的稳定顺序分配单来源配额并维护全局剩余渲染点数预算，单来源累计点数超出配额即中止该分片本批处理并记 E_QUOTA_EXCEEDED，预算不足时未处理样本进入待办队列并以 E_RENDER_BUDGET_PENDING 标记且下批优先处理；每个任务携带由来源分片标识、样本标识与阶段名派生的稳定排序键，无论线程调度顺序与并发度如何最终输出顺序与串行一致。
7. 实现阶段化快照整体替换、强制终止后的恢复判定与异常注入隔离：将加载校验、模板解析、渲染、质量打分与去重统计划分为阶段，各阶段产物连同待办队列、已完成模板修订游标与已消耗预算先写入临时目录再整体替换提交，清单记录全局版本号、配置哈希、模板修订链指纹与各阶段产物版本，启动时以版本号与配置哈希比对识别版本变化决定续跑或重建；以独立注入清单对指定样本或模板施加模板修订环、槽位填充值缺失、样本引用不存在的修订与非有限质量分等真实输入故障，注入项编号须写入报告以证明命中，单条失败不得中断其余样本处理。
8. 实现 Tkinter 诊断界面与可复核报告输出：界面展示模板修订链结构与生效槽位、逐样本渲染摘要、质量分与去重簇、失效与复用条目、待办队列与业务码计数，支持编辑模板修订与去重阈值并触发增量重算；报告中须含逐模板样本数、去重剔除数、渲染点数消耗与端到端耗时，界面快速结论在共同完成范围内须与账本权威结果逐字段一致，差异项须标明所属阶段。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
