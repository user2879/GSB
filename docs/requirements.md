需求说明只有一纸条目，代码与配置尚未存在；项目根目录当前只有一个空文件夹，需要建立完整的 Python 项目，交付一个面向多视图三维重建的多分辨率体素占位诊断组件与可重复实验环境。业务对象是本地确定性合成的多视图图像及其相机参数，重建管线依次执行特征提取、跨视图匹配、三角化、深度图生成与基于体素的三维占位重建，全部数值在定点整数域计算。使用者会反复替换单张视图、修改相机外参、调整三角化最小视差与体素尺寸，并要求每次编辑后只重算真正受影响的特征、匹配对、三角化点、深度图像素与体素（含子体素），同时保证任意执行顺序与预算受限下结论唯一可复核。

任务环境与准备：
在 WSL Ubuntu 上安装 Python 3.10 或更高版本，并确保 tkinter 可用（例如安装 python3-tk）。
安装 NumPy 1.24 或更高版本（pip install 'numpy>=1.24'），仅使用标准库与 NumPy，不引入其他第三方依赖。
在项目根目录下创建 data/ 与 config/ 目录，由脚本按固定整数种子生成多视图 PNG 图像、相机内外参与编辑命令流样本，不依赖任何外部数据集或网络。

业务要求：
1. 实现视图图像、相机参数、重建配置与编辑命令流的加载校验层：校验 PNG 容器头、固定分辨率与像素模式，校验每视图相机内参矩阵可逆、外参旋转部分正交、视图序号唯一且与图像一一对应、最小视差与残差阈值为正整数，对不合规输入输出业务码并进入失败清单。
2. 实现逐视图确定性特征提取与跨视图匹配阶段：特征由分块梯度与颜色统计在定点整数域计算并逐视图记录特征点坐标与内容指纹，匹配仅在同一匹配对的视图间进行，匹配对顺序与内点计数累加顺序固定为视图序号升序与特征点坐标字典序。
3. 实现三角化与深度图生成阶段：三角化在定点域按匹配对内点求解三维坐标并逐点记录残差与量化舍入方向，深度图按分辨率与量化档位生成并逐像素记录深度整数与舍入方向；深度冲突恰落在量化半步内时按固定规则决断并标记边界像素。
4. 实现残差驱动的体素细分与三维占位判定内核：每个体素的分辨率由参与它的三角化点残差均值与深度图一致性分数在定点域合成后与残差阈值比较决定，达到阈值即细分为子体素并记录父子标识与细分依据，未达阈值则判定占位并记录占位依据。
5. 实现特征、匹配对、三角化点、深度图像素与体素（含子体素）的精确失效传播与复用账本：为各阶段产物计算由上游内容指纹、参数指纹与量化档位派生的缓存键，并记录每个体素引用的三角化点集合、深度图像素与父体素标识；替换单视图或修改外参后只使引用它的产物及其下游失效。
6. 实现视图数规模自适应策略选择器与全局重建点数预算、单视图配额约束下的并行调度：依据视图数、匹配对总数与当前档位下预计子体素数，从预置策略表中选择特征抽取精度、匹配范围与体素细分顺序，选择须实际改变后续计算路径与账本；调度器按视图序号与体素路径的稳定顺序消耗预算，超配额中止并保留待办。
7. 保证任意编辑命令序列后增量运行与从空白全量重建逐字段一致，并保证任意并发度、任意预算耗尽时机与任意视图完成顺序下结果与串行执行一致：每个视图任务、匹配对任务与体素任务携带稳定排序键，最终逐视图特征、匹配对、三维点坐标、深度图、体素细分与占位结论均须与全量运行逐字段相同。
8. 实现阶段化快照整体替换、恢复判定与 Tkinter 诊断界面：将加载校验、特征提取与匹配、三角化、深度图生成与体素细分占位划分为阶段，各阶段产物与待办队列先写入临时目录再整体替换提交，清单记录全局版本号、配置哈希、相机参数哈希与各阶段产物版本；界面展示关键指标并支持编辑参数触发增量重算。
