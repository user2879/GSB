当前为空白工作区，需要从零构建一个面向表格数据的线性模型正则化训练实验台，交付算法实现与可复现的实验环境。输入为本地 YAML 实验配置与按固定种子确定性生成的合成表格数据描述（数值列、类别列、缺失值、冗余列与二值目标列）。实验台需完成 L2 岭回归、L1 套索与弹性网络三种正则化训练的确定性求解，并把学到的模型系数在两种交换版本之间流转：v1 为定宽文本行（模型名、特征序号、千分比整数系数、整数惩罚码、截距千分比），v2 为 JSON（浮点系数、命名正则化方案、命名收敛状态与精度标签）。用户会反复调整惩罚系数、混合比例与特征白名单，并希望每次改动只重训真正受影响的模型，其余模型直接复用已持久化产物，且中断后可续跑得到与全量重训一致的结果。

任务环境与准备：
确认本地已安装 Python 3.10 及以上版本，并能在命令行直接调用 python。
安装 NumPy 与 PyYAML：pip install numpy pyyaml，无需其他外部服务。
在空工作区新建项目目录，准备本地 YAML 实验配置与合成数据描述文件，数据由程序按固定种子生成，不依赖外部数据集。
准备一份 v1 定宽模型样例与一份 v2 JSON 模型样例作为解析输入，并预留快照输出目录与旁路元数据目录。
Windows 下运行需保证控制台支持 UTF-8 输出，退出码使用整数。

业务要求：
1. 实现配置、数据与双版本模型文件加载层：读取 YAML 配置与列描述，按列类型与固定种子确定性生成表格数据并完成缺失填充（数值列取训练均值、类别列取众数）与类别编码；解析 v1 定宽行与 v2 JSON 两版本模型文件并统一为中间表示，v1 的千分比系数、整数惩罚码与截距须按字段宽度解析，v2 的浮点系数须保留精度标签；对未知列、正则化方案不在枚举内、混合比例不在零到一之间、千分比越界与字段宽度不足分别输出 E_CONFIG_INVALID、E_SCHEME_UNKNOWN、E_MIX_RANGE、E_SCALE_RANGE、E_FIELD_TRUNCATED 业务码。
2. 实现三种正则化的确定性批量梯度下降训练：L2、L1 与弹性网络的损失须显式包含对应正则项及其梯度贡献，弹性网络按混合比例线性组合两种惩罚；按固定批量划分与固定批量顺序执行，L1 次梯度在系数为零处采用固定决断，逐轮记录损失轨迹与系数快照摘要；同一样本集与配置下多次运行必须得到逐轮损失与最终系数完全一致，禁止依赖运行时全局随机状态。
3. 实现两版本模型文件双向转换与降级信息旁路：训练完成后按配置的交换版本写出模型；v1 升 v2 时千分比系数与截距按精确换算转为浮点并生成精度标签、整数惩罚码按码表映射为命名方案与命名收敛状态；v2 降 v1 时浮点系数按四舍五入还原千分比并把截断残差、精度标签与被丢弃的命名信息写入旁路元数据文件；降级信息须能被后续加载重新引用，且同一模型经两版本往返后按中间表示比较的系数偏差不超过配置容差。
4. 实现基于内容指纹的模型级精确失效判定：为数据切片、标准化统计量、每个候选模型的训练产物与版本转换产物计算由上游内容指纹、惩罚参数指纹与交换版本号派生的缓存键，并记录每个模型引用的特征白名单与样本集合；当修改某方案的惩罚系数或混合比例、调整特征白名单、替换单列数据或切换交换版本时，仅将受影响模型及其版本转换产物标记失效并纳入重训，未失效模型必须直接复用已持久化产物且不得重新训练，复用与重算清单须可审计。
5. 保证任意编辑序列后增量运行与从空白全量重建的逐字段一致：从任意初始状态施加包含正则化方案切换、惩罚系数与混合比例调整、特征白名单变更、单列数据替换与交换版本切换的编辑序列，每次运行得到的逐模型系数、逐轮损失轨迹、验证指标、复用与重算清单顺序以及失败清单顺序，必须与按相同最终数据与配置一次性全量运行的结果完全相同，不得因特征白名单顺序或任务完成顺序产生差异。
6. 实现全局训练轮次预算与单模型配额的调度控制：调度器维护全局剩余训练轮次预算并按方案名与惩罚参数指纹的稳定顺序分配单模型配额，某模型累计消耗轮次超出配额即中止该模型并记 E_MODEL_BUDGET_EXHAUSTED 且不得进入验证指标汇总，全局预算耗尽时对未开始模型输出 E_TRAIN_BUDGET_EXHAUSTED 并保留待办清单；每批结束按配置间隔提交模型快照，已消耗预算随快照持久化。
7. 实现阶段化快照整体替换与恢复判定：将加载校验、标准化、模型训练、版本转换划分为阶段，各阶段产物先写入临时目录再整体替换提交，清单记录全局版本号、配置哈希、数据指纹、已完成模型列表、已消耗轮次预算与各阶段产物版本；启动时以清单版本号与配置哈希、数据指纹判定是否续跑，不一致时输出 E_SNAPSHOT_STALE；收到可处理的退出信号时完成当前模型产物落盘后以整数退出码退出，强制终止后的恢复只能依据已提交的持久化快照。
8. 实现并发训练与串行结果一致性及异常隔离：使用线程池并发训练彼此独立的候选模型，最大并发数取自配置且不得超过其上限，每个模型任务携带由方案名与惩罚参数指纹派生的稳定排序键；单模型在标准化、梯度更新或版本转换阶段抛异常时记录模型标识、轮次、阶段名、业务码与异常类型并继续训练其余模型，失败模型不得进入验证指标汇总；无论线程调度顺序、并发度与失败发生顺序如何，最终模型顺序、损失轨迹、系数与失败清单顺序须与单线程按稳定排序键执行一致，并输出含各阶段耗时与预算消耗的 JSON 诊断报告。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。
