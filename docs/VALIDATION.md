# 验证记录

验证环境：Python 3.11（标准库 `sqlite3`、`unittest`），本地执行、无网络、无第三方依赖。
目标运行环境为 Windows 10/11 + Python 3.11/3.12（仅标准库，Tkinter 随官方安装包提供）。

## 自动化测试

`python -m unittest discover -s tests` 共 29 个用例，全部通过，覆盖：

- 链强校验：重复代际、负序号、父引用缺失、环、容量非法、区间不连续、
  主键乱序/重复、规则引用未知区间、废弃区间带主键、非法动作（均 `E_CHAIN`）。
- 片段切分：6→3+3、8→4+4、11→4+4+3 的确定性拆分；不可行分区抛 `E_BOUND`。
- 迁移：每代片段完整覆盖键空间；继承逐字节一致并记录来源；重写解除旧版本引用；
  继承键不一致抛 `E_INHERIT`。
- 清理：读视图打开时延迟、关闭后清理、重复运行幂等。
- 游标：分页无空洞无重复；良性拆分/合并可安全续读；破坏性重包抛 `E_CURSOR`
  并定位片段与主键；同代际在有/无迁移活动下结果逐字节一致。
- 快照与重放：整体替换后无新增/误删，重放逐字段一致；
  `E_BOUND / E_INHERIT / E_CLEAN` 三类注入均被精确定位。
- UI：无头环境下模块可导入，启动时给出明确降级提示。

## 六场景演示

`python -m snapshot_migration.cli demo --chain samples/snapshot_chain.json \
  --out artifacts/demo_output.txt`

连续两次运行，剔除临时工作目录行后 `diff` 完全一致，输出顺序与内容稳定可复核。
场景顺序：

1. 多代有序迁移、片段拆分与合并；
2. 裂合轨迹与继承来源映射；
3. 并发读视图下废弃区间先延迟后清理、重跑幂等；
4. 双维游标续读、版本锚定与 `E_CURSOR` 失效原因；
5. 快照保存、重开整体替换、差异分类与重放校验；
6. 三类异常注入与恢复重放。
