在空白工作区构建一个可集成的中文分词与词性标注领域组件与完整示例，核心解决词典与概率表增量更新时的依赖失效判定问题。输入为本地样本目录：一份 UTF-8 文本行文件（每行含句子 ID 与原始文本）；一份基础词典（每行“词 词频 词性”）；一份词性标注概率表 JSON（词性转移概率与词性发射概率，以自然对数存储）；一份增量配置 JSON（并发数、词典变更模式、快照提交间隔、低置信度阈值、平滑值）。组件需实现基于词典的最大匹配分词、未登录词 HMM 维特比识别、词性标注维特比解码，并支持在运行中增量修改词典（增删词条或调整词频）或替换概率表。每次修改后必须仅重算引用受影响词条或概率表的句子，未失效句子直接复用缓存结果，且增量运行得到的最终输出必须与从空白状态全量运行逐字段一致。

任务环境与准备：
准备 Windows 环境并安装 Python 3.10 及以上版本与 NumPy（版本 1.24 及以上）。
准备本地 UTF-8 文本行样本文件，每行格式为“句子ID<TAB>文本”，句子 ID 唯一且文本非空。
准备本地基础词典文件，每行“词 词频 词性”，词频为正整数，词性为预定义集合内的标记。
准备词性标注概率表 JSON，包含词性转移概率与发射概率，概率值以自然对数存储，缺失发射使用配置平滑值。
准备增量配置 JSON，指定并发数、快照提交间隔、低置信度阈值与平滑值，确保并发数为正整数。

业务要求：
1. 实现文本行加载与分词阶段：逐行解析句子 ID 与原始文本，校验 ID 唯一且文本非空；基于词典执行正向最大匹配，同长匹配按词频降序、再按词形字典序决断，输出每个词的起止位置、词形与匹配依据；非法行输出 E_SENTENCE_INVALID 并进入失败清单。
2. 实现 HMM 未登录词识别与词性标注：对连续单字片段以自然对数域执行维特比解码识别未登录词；对分词结果使用词性转移与发射概率做对数域维特比标注，输出每个词词性、局部路径得分与整句归一化对数概率；发射缺失时使用配置平滑值并记录命中次数。
3. 实现基于内容指纹的词典与概率表依赖失效：为每个句子计算由文本指纹、命中词条集合指纹与概率表版本派生的缓存键；当词典单条增删或词频调整时，仅将命中受影响词条的句子标记失效；概率表替换时使全部句子失效；未失效句子必须复用缓存且不得重新计算。
4. 实现版本化快照整体替换与恢复一致性：分词、未登录词识别、词性标注、汇总各阶段产物先写入临时目录再整体替换提交，manifest 记录全局版本号、词典哈希、概率表哈希、已完成句子列表与各产物版本；启动时以版本号、词典哈希与概率表哈希判定续跑，不一致输出 E_CONFIG_MISMATCH 并拒绝续跑。
5. 保证编辑序列下增量运行与全量运行逐字段一致：从任意初始状态施加包含词典增删、词频调整、概率表替换与单句文本替换的编辑序列，每次编辑后增量运行得到的每句分词序列、词性序列、路径得分、失效复用清单与失败清单顺序，必须与从空白工作区按相同最终输入全量运行的结果一致。
6. 实现并发处理与串行结果一致性：使用线程池并发执行句子分词与标注，最大并发数取自配置；每个句子任务携带由句子 ID 与阶段名派生的稳定排序键，无论线程调度顺序与并发度如何，最终句子顺序、分词结果、词性序列与失败清单顺序必须与单线程串行执行逐字段一致。
7. 实现低置信度观测与异常隔离：记录每个词的边界置信度与标注路径得分，低于低置信度阈值的词计入统计并输出清单；单句在分词、识别或标注阶段抛异常时记录句子 ID、阶段名、业务码与异常类型并继续其余句子，后续编辑不得再对该句产出结果。
8. 实现可处理退出语义与统计报告输出：收到可处理的退出信号时完成当前句产物与快照原子替换后以整数退出码 0 退出，强制终止后仅依据已完整替换的快照恢复；每次完整运行生成 JSON 报告，包含总句数、成功与失败句数、低置信度词数量、词典与概率表哈希、快照版本号、失效与复用句子数及失败清单，报告以临时文件加原子替换方式写盘。

执行约束：不使用 Docker 或其他容器环境；使用本地确定性样本验证，不访问未授权目标。按上述任务意图交付相应代码、测试或技术说明，记录实际验证结果。

验收：
