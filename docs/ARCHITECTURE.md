# 技术说明

## 模块划分

| 模块 | 责任 |
|---|---|
| `config.py` / `data_spec.py` | YAML 解析、规范化、逐方案校验、分析配置哈希 |
| `data.py` | SHA-256 派生随机流、确定性生成、缺失填充、类别编码、目标生成 |
| `crossing.py` | 组合枚举、组合排序、确定性哈希编码、预算降级、设计矩阵 |
| `reductions.py` | 标准化、PCA、随机投影、方差筛选、候选维度指标 |
| `metrics.py` | 下游指标、两档位决策、四阶段逐样本误差和归因 |
| `boundary.py` | 维度对、交叉特征对、阈值边界、敏感翻转分类 |
| `cache.py` | 内容寻址产物、命中/失效/退役账本、线程安全读写 |
| `snapshot.py` | 不可变阶段目录、原子清单提交、恢复与陈旧判定 |
| `evaluation.py` | 阶段编排、线程池、稳定排序、报告生成入口 |
| `report.py` | JSON/Markdown 报告与分析指纹 |

## 确定性来源

1. 所有伪随机值来自 `SHA-256(seed|路径|列|行|计数器)`，不共享进程 RNG 状态。
2. 组合顺序固定为 `(阶数升序, 列名元组字典序)`。
3. 设计矩阵、标准化矩阵、投影结果、逐样本指标均按固定数组、固定数组类型计算。
4. 随机投影种子由场景作用域、输入特征名、投影参数和分量数派生；`float32` 与 `float64` 共用同一双精度矩阵定义后再按档位转换。
5. PCA 每个主成分以最大绝对分量所在位置为正方向。
6. 缓存账本、边界候选、敏感样本、失败清单和任务表均使用显式稳定键排序。

## 缓存键

每个阶段使用以下形式：

```text
key = SHA256({
  schema, kind,
  upstream_content_fingerprint,
  parameter_fingerprint,
  precision
})
```

- 交叉编码参数只包含白名单、阶数上限、预算、溢出策略、类别映射与精度，不包含降维/判定参数。
- 标准化只包含上游设计和标准化参数。
- 每条降维路径只包含标准化上游、该路径参数与投影作用域。
- 指标只包含上游投影和指标名。

因此修改 PCA 分量数只失效 PCA reduction 与 PCA metrics；随机投影、方差筛选、交叉编码和标准化保持命中。测试对此逐项断言。

## 快照协议

阶段顺序固定为：

1. `crossing`
2. `reductions`
3. `metrics`
4. `diagnostics`

提交过程：

1. 在 `snapshot/.tmp/<stage>-<random>` 写入 `state.json` 并 `fsync`。
2. 目录整体重命名到不可变版本目录 `stages/<stage>/<stage>-<payload_hash>`。
3. 原子替换根 `manifest.json`，登记阶段版本、负载指纹、依赖指纹和 `complete` 状态。

启动时先校验 `schema_version`、全局版本、配置哈希和两档位精度指纹。任一不一致即设置 `E_SNAPSHOT_STALE` 并拒绝加载任何阶段。`.tmp` 中未进入清单的目录不会被恢复，只记录为被忽略的未完成产物。

## 误差与边界

四阶段误差均为逐样本、逐元素最大绝对差：

- 交叉编码：两档位设计矩阵。
- 标准化：两档位标准化矩阵。
- 投影：两档位降维输出。
- 最终指标：两档位逐样本指标。

首次超过阶段容差的环节即 `first_exceeded_stage`；若无越界，则以最大归一化误差选择主环节。下游判定为 `metric >= threshold`，阈值支持固定值或双精度参考中位数。

边界候选：

- 保留维度：候选维度累计解释方差/保留方差比例之差进入邻域。
- 交叉特征：与目标绝对 Pearson 相关系数之差进入邻域。
- 判定阈值：样本双精度指标与阈值之差进入邻域。

翻转来源固定分类为：编码/标准化舍入（`encoding_rounding`）或投影/最终指标累加（`projection_accumulation`）。

## 并发协议

任务键包含阶数、路径与样本 ID 指纹。任务提交顺序为：

```text
(场景 ID, 样本规模, 阶数, 路径秩)
```

线程池大小取根配置、场景配置和 CLI 上限的最小值，不会超过配置上限。所有共享缓存使用逐键锁；最终账本按产物阶段、场景、规模、阶数、路径、精度和谱系排序。测试在并发度 1 与 3 下比较方案表、边界表、敏感清单、失败清单和账本，要求逐字段相等。
