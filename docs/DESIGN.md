# 设计说明：本地确定性多标签图像分类数据编辑应用

## 1. 范围与约束

- 仅依赖 Python 3.10+、NumPy、Pillow；不使用深度学习框架、GPU 或容器。
- 数值管线不读取也不修改 NumPy 全局随机状态；样本生成使用独立的
  `numpy.random.Generator`，由 `(base_seed, sample_index, variant)` 派生。
- 所有跨进程需要保持一致的产物均通过规范化 JSON + SHA-256 生成内容指纹。

## 2. 模块结构

| 模块 | 职责 |
| --- | --- |
| `errors.py` | 业务码与异常层级（`E_SAMPLE_FORMAT`、`E_LABEL_UNKNOWN`、`E_BBOX_OUT_OF_RANGE`、`E_FEATURE_BUDGET_PENDING` 等） |
| `config.py` | 标签、比例、特征、分类器、阈值、定点枚举、并发与预算的严格校验 |
| `datagen.py` | 固定种子合成 PNG 与标注 JSON，覆盖共现、遮挡与椒盐噪声 |
| `injection.py` | 独立故障注入配置，注入仅作用于内存，不污染源数据 |
| `validation.py` | 阶段一：容器头、尺寸、标注结构、标签合法性与整数边界框校验 |
| `fixedpoint.py` | 定点量化枚举、舍入策略、整数/残差保留与阈值整数化 |
| `features.py` | 阶段二：RGB 解码、颜色直方图、HOG、拼接特征与定点化 |
| `classifiers.py` | 阶段三：逻辑回归/最近质心/kNN、稳定 sigmoid、逐标签判定与边界标记 |
| `metrics.py` | 阶段四：逐标签混淆矩阵、P/R/F1/Accuracy 与聚合摘要 |
| `cachekeys.py` | 内容指纹缓存键、规模档位与复用/重算审计排序 |
| `budget.py` | 单批特征点预算、可回放扣减序列与待办队列 |
| `snapshot.py` | 暂存目录、内容寻址产物、原子替换提交与清单恢复 |
| `concurrency.py` | 线程池执行器与稳定排序键聚合 |
| `pipeline.py` | 四阶段编排、失效判定、预算阻塞、报告与快照提交 |
| `plan.py` / `runner.py` / `cli.py` | 编辑计划、工作区物化、全量/增量入口与命令行 |

## 3. 确定性与定点化

- 特征模式：`color_hist`、`hog`、`color_hog`。HOG 使用固定单元网格、无符号
  方向角与单元 L2 归一化；直方图使用固定 bin 边界。
- 量化枚举：`Q0.8/8`、`Q1.15/15`、`Q2.30/30`、`scale10`；舍入枚举：
  `HALF_UP`、`TRUNC`、`HALF_EVEN`。
- 产物同时保存定点整数与 12 位小数舍入的量化残差，可还原浮点向量。
- 概率与阈值都量化为同一标度的整数；判定使用整数比较，阈值相等按
  `positive_on_equal` 判正并标记 `boundary=true`，消除浮点歧义。

## 4. 三种分类器

- `logreg`：逐标签二分类，全批量梯度下降，固定样本顺序、学习率、L2 与轮数，
  逐轮记录确定性损失曲线。
- `centroid`：正负类内均值质心，欧氏距离，原始分数为负质心距离减负质心距离。
- `knn`：按 `(距离, 样本序号)` 建立全序邻居顺序，支持 uniform/distance 投票。
- 三者共享稳定 sigmoid 归一化与定点概率量化；同一输入重复运行逐字段一致。

## 5. 精确失效判定

缓存键由以下指纹组合而成：

- 特征键：样本名 + 图像内容指纹 + 抽取参数指纹（模式、bin、cell、量化、舍入）。
- 模型键：分类器超参指纹 + 引用样本图像指纹集合 + 规模档位 `Txx_nN`。
- 决策键：模型键 + 阈值 + 量化标度。
- 指标键：决策键 + 分类器/标签。

失效范围：

- 替换/新增图像：仅该样本特征，以及引用该样本矩阵的模型、决策、指标重算。
- 新增标签：旧标签模型可复用，仅新标签全链路重算。
- 删除标签：仅删除对应标签下游产物，其余标签保持复用。
- 调整阈值：模型分数复用，仅决策与指标重算。
- 修改某分类器超参：仅该分类器模型重算，其它分类器复用。
- 切换特征方式：全部特征与全部下游产物重算。

## 6. 预算调度与快照

- 仅对需要实际计算的特征任务计费；缓存复用不消耗预算。
- 调度按稳定键排序，跨批待办优先；扣减记录包含序号、样本、成本、扣减前后余额。
- 待办未清空时阻塞打分/指标阶段，已完成特征数值不受预算耗尽影响。
- 快照分为 `staging/` 与 `committed/`，产物内容寻址，清单通过原子 `os.replace`
  整体替换；中断后只可能观察到上一个完整提交，恢复从清单游标继续。

## 7. 并发一致性

任务携带由阶段、样本、分类器、标签派生的稳定键。线程池返回结果后统一按键排序，
因此并发度、操作系统调度和失败到达顺序都不影响最终样本顺序、概率、判定、指标、
审计清单与失败清单。

## 8. 报告字段

每次运行输出 JSON 报告，包含：逐样本逐标签概率/判定、指标摘要、边界样本、
决策记录、复用/重算清单与计数、合并审计清单、预算扣减、待办队列和失败清单。
`runner.comparable_state` 抽取与运行实例无关的字段，用于全量/增量逐字段比对。

## 9. 验证结果

完整测试：`python3 -m pytest tests -q`，当前 41 个测试全部通过。

验收脚本：`python3 acceptance/run_acceptance.py`，四个场景全部通过：

1. 8 批增量编辑与最终状态一次性全量重建逐字段一致。
2. 小预算下出现待办并在后续批次排空；模拟 SIGINT 后清单游标停在已提交批次，
   恢复后到达最终游标。
3. 单线程与 16 线程（配置上限内）报告逐字段一致。
4. 四类注入故障全部命中预期业务码且保留注入编号，其余样本继续产出预测。
