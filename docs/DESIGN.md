# 技术说明：多视点光度立体 × 可微渲染交替优化

仅依赖 Python 3.10+ 标准库与 NumPy，无 GPU、无容器、无外部服务。

## 1. 总体结构

| 模块 | 职责 |
| --- | --- |
| `config.py` | 观测/求解/优化/容差的纯数据配置，全部可 JSON 序列化 |
| `geometry.py` | 固定种子程序化高度场、中心差分法向、反照率贴图 |
| `forward.py` | 光源 L2 单位化、相机位姿、Blinn-Phong 前向模型与解析导数 |
| `generator.py` | 确定性观测集与逐像素真值清单生成、原子落盘 |
| `photometric.py` | 多视点加权最小二乘光度立体（显式镜面扣除 + Huber IRLS） |
| `differentiable.py` | DR 损失、解析梯度、有限差分核对、瓦片增量渲染与核对 |
| `conflict.py` | 阶段间逐像素语义对照与确定性冲突定位 |
| `faults.py` | 可序列化异常注入配置，全部作用于副本 |
| `persistence.py` | 原子写、内容哈希、提交标记、崩溃垃圾清理 |
| `pipeline.py` | 交替优化编排、逐轮持久化、强制终止恢复 |
| `verification.py` | 仅核对用真值比对（求解路径禁止导入） |
| `cli.py` | 命令行入口 |

## 2. 前向模型与数值口径

正交相机、线性光（无伽马、无色调映射），每个视点（相机 × 光源）观测：

```
I = max( rho * max(n·l, 0) + ks * max(n·h, 0)^sh , 0 )
```

* 光源原始方向在 `config.py` 声明，运行时按
  `l_hat = l / sqrt(lx²+ly²+lz²)` 做 L2 单位化，零向量抛 `E_ZERO_LIGHT`。
* 计算全程 float64；观测落盘为小端 float32（`<f4`），真值法向/反照率落盘 float64。
* 相机系向量满足 `v_cam = R v_world`；世界系设计方向使用逆变换
  `v_world = Rᵀ v_cam`（这是多视点求解正确性的关键）。
* 镜面参数 `ks=0.15`、`sh=12` 为前向模型固定常量，不参与优化。

## 3. 光度立体（独立实现，不读真值）

每像素把 12 个有效视点堆叠为定长缓冲（无效槽权重为 0），全像素向量化批处理：

1. 设计矩阵 `A` 固定为世界系光源方向，不随迭代估计改写（避免自洽偏差）；
2. 加权正规方程 `AᵀW²A g = AᵀW² ỹ`，其中 `ỹ = max(y − 镜面预测, 0)`，
   镜面预测由当前法向与固定 `ks/sh` 显式计算；
3. SVD 求解未缩放向量 `g = rho·n`，归一化得单位法向，
   反照率由一维非负加权最小二乘得到并裁剪到 `>= 0`；
4. Huber IRLS（调谐 1.345、权重下限 0.05、8 轮）压制残余外点；
5. 条件数取设计矩阵奇异值比 `sqrt(λmax/λmin)`，只统计非零奇异值，
   超过阈值 30 标病态并给法向夹角/反照率误差区间；
6. 有效视点少于 4 抛 `E_DEGENERATE_VIEWS`，非有限反照率抛
   `E_NONFINITE_ALBEDO`。

## 4. 可微渲染（独立实现，不共享缓存）

* 损失 `L = mean (I_render − I_obs)²`，只统计有效视点头像内像素。
* 解析梯度覆盖法向三分量与反照率：先对单位法向求导，
  再经归一化雅可比 `J = (I − n̂n̂ᵀ)/|n|` 映射回原始参数。
* 中心有限差分（eps=1e-7）在确定性像素样本上逐分量核对，容差 1e-6。
* 每轮更新后法向重新归一化、反照率裁剪非负。

## 5. 交替顺序与收敛

每轮固定顺序：PS 独立求解 → 阶段间对照 → DR 独立解析梯度 → 增量参数更新
→ 瓦片增量/全量渲染核对 → 原子提交。

* 首轮用纯 PS 解初始化；后续轮次 PS 独立解与当前 DR 参数按 `ps_blend=0.35`
  融合，使 PS 保持独立语义而不抹掉 DR 的持续增量。
* 收敛条件：相邻轮损失下降绝对值 `< 1e-12`，或达到迭代上限（默认 12）。
* 全程无随机数调用，固定顺序下两次运行的逐轮内容哈希一致。

## 6. 冲突定位

逐像素比较 PS 独立解与 DR 当前参数：法向夹角（度）阈值 5°、
反照率绝对偏差阈值 0.05，任一越界即冲突。记录两阶段取值、夹角、
两者梯度方向夹角与幅度；像素按行优先、列升序排序并给首个冲突坐标。
判定不使用整体损失接近度。

## 7. 增量/全量一致性

图像按 32×32 瓦片（行优先、列升序）声明重算范围。每轮把增量瓦片拼接结果
与当前参数的全量重渲染按 `atol=1e-10, rtol=1e-12` 逐像素核对，
并核对损失；首个分歧瓦片即抛 `E_RENDER_DIVERGE`，附依赖参数切片，
不允许放宽容差掩盖分歧。

## 8. 异常注入与业务码

| 业务码 | 层级 | 触发 | 诊断 |
| --- | --- | --- | --- |
| `E_NONFINITE_ALBEDO` | 参数 | 反照率副本写入 NaN/Inf | 受影响像素、计数 |
| `E_ZERO_LIGHT` | 参数 | 光源方向副本置零 | 光源索引 |
| `E_DEGENERATE_VIEWS` | 参数 | 有效视点 < 4 | 最小有效视点数、像素清单 |
| `E_ILL_CONDITIONED` | 状态 | 条件数阈值越界 | 病态像素（不中断） |
| `E_VIEW_SKIPPED` | 管线 | 渲染跳过指定视点 | 视点编号 |
| `E_RENDER_DIVERGE` | 管线 | 增量/全量分歧 | 首个瓦片、依赖参数 |
| `E_NO_CHECKPOINT` | 管线 | 恢复时无已提交快照 | 工作区 |

注入配置是 JSON 可序列化数据，随 `run_manifest.json` 落盘；所有注入只改副本。

## 9. 原子持久化与恢复

* 每个产物先写同目录唯一 `.tmp`，`fsync` 后 `os.replace` 原子替换，
  再写 `*.committed` 标记；读取方只承认带标记的产物。
* 每轮提交：轮次记录 JSON、冲突清单 JSON、PS/DR 法向与反照率、渲染图像。
* 受控退出写 `status.json=completed`；强制终止模拟写 `crashed`。
* 恢复时先清理所有 `.tmp` 与无主标记，只依据最近一轮完整提交的快照续写；
  因全程确定性，续写轨迹与未中断运行逐字节一致（测试与示例均已验证）。
