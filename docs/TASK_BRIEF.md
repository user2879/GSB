在空白工作区构建一个面向长序列注意力热块稀疏化的算子诊断应用，核心业务问题是：序列长度过长时只对每个查询块保留少量键块参与打分，而哪些键块入选由上一轮统计量决定，形成“统计量—选择—打分—再统计”的反馈环；同时得分以定点整数累加，选择位图又被缓存，任何一次选择变更都必须精确传导到依赖它的查询块与热块统计。输入为本地样本目录：一份按固定种子生成的小端二进制张量包（查询、键、值三张量的形状描述与 float32 数据块）、一份候选块预筛参数 JSON（查询块长、键块长、每查询块初始候选键块数、分数下界比例、注意力温度）、一份定点与容量配置 JSON（定点小数位宽与量化档位、乘积累加位宽、饱和与舍入模式、热块表容量、每轮热块保留数、最大选择迭代轮数、线程池并发数、单批打分点数预算、快照提交间隔轮数、容差），以及一份编辑命令流 JSON（替换某个查询块的数据、修改预筛参数、调整位宽档位、替换部分键块数据）。应用需完成二进制张量解析、块级定点打分、热块选择反馈迭代、选择位图与热块表的依赖失效传播、预算受限的并行打分、阶段快照恢复与可重复诊断报告。

任务环境与准备：
Windows 本地环境，安装 Python 3.11，无需 GPU 或外部网络
安装 NumPy，使用 pip 从本地已备好的安装源完成
在工作区新建项目目录与本地样本目录，样本由随项目提供的固定种子脚本生成
准备小端二进制张量包、预筛参数、定点与容量配置及编辑命令流各一份，确保形状描述与数据长度自洽
准备独立注入配置文件与示例编辑序列，供运行演示与异常验证使用

业务要求：
1. 实现张量包与配置加载校验层：解析小端二进制张量包的形状描述与数据块，校验形状描述与数据长度一致、序列长度能被块长整除或按补齐规则标注、定点小数位宽与量化档位在允许枚举内、乘积累加位宽大于定点位宽、每查询块初始候选键块数不超过键块总数；解析预筛参数、定点容量配置与编辑命令流，校验命令引用的查询块与键块存在、温度为正有限数；非法输入分别输出 E_TENSOR_LAYOUT、E_CONFIG_INVALID��E_COMMAND_REF 业务码并进入失败清单。
2. 实现块级定点打分阶段：按查询块长与键块长切块，把查询与键数据按量化档位转为定点整数，乘积在声明位宽的整数缓冲中累加，溢出按饱和策略处理并记录溢出块对与累加位置；再把整数累加结果乘以缩放因子后按舍入模式做确定性舍入，累加顺序固定为查询块内行号升序、键块内列号升序；同一输入与配置下两次运行必须逐元素一致，并输出每块对的定点累加值、缩放因子、舍入模式与块对指纹。
3. 实现热块选择反馈迭代：每轮按上一轮块对得分与分数下界比例筛出候选键块，按得分降序保留每查询块最多初始候选键块数，得分相同按键块序号升序决断；再以新选中的块对重新打分与统计，直到选择位图不再变化或达到最大迭代轮数；达到上限仍未收敛时输出 E_SELECT_UNCONVERGED 并保留最后位图与迭代轨迹，不得静默返回中间结果。
4. 实现选择位图与热块表的依赖失效传播：为每块对打分结果、每查询块选择位图与全局热块表分别计算由上游内容指纹、预筛参数指纹、位宽档位与迭代轮次派生的缓存键，并记录位图引用的块对集合、热块表引用的位图行集合；当某查询块数据被替换或预筛参数变更时，只使引用该查询块的位图行、由这些行贡献的热块表条目及其下游统计失效，未失效块对必须直接复用持久化算子且不得重算，复用与重算清单须可审计。
5. 实现热块表容量与保留数约束下的确定性更新：热块表按累计选中次数与累计得分排序，容量满时按最少选中次数、再按键块序号升序逐出；每轮保留数与容量冲突时以容量上限为准并记录被压制条目；某键块被逐出后若再次入选必须重新累计，禁止继承旧计数；输出每轮热块表条目、逐出记录与保留压制记录，且热块表内容须可从持久化算子与账本重建。
6. 实现单批打分点数预算与单查询块配额约束的并行调度：块对打分任务通过线程池并发执行，最大并发数取自配置且不得超过；调度器按查询块序号稳定顺序分配单查询块配额并维护全局剩余打分点数，单查询块超配额中止并记 E_QBLOCK_BUDGET_EXHAUSTED，全局预算耗尽时输出 E_SCORE_BUDGET_EXHAUSTED 并保留待办块对队列，下批优先处理待办；无论线程完成顺序如何，预算扣减序列须与串行按稳定键执行的结果完全一致。
7. 保证任意编辑序列与任意预算耗尽时机下增量运行与从空白全量重建逐字段一致：从任意初始状态施加包含查询块替换、键块替换、预筛参数调整、位宽档位切换与热块容量变更的编辑序列，每次运行得到的最终选择位图、每块对定点累加值与缩放因子、热块表条目与逐出记录、失效复用清单、预算扣减序列与失败清单，必须与从空白工作区按相同最终张量与配置一次性全量运行的结果完全相同。
8. 实现阶段化快照整体替换、恢复判定、异常注入隔离与诊断报告：将张量解析、块级打分、选择迭代、热块汇总划分为阶段，各阶段产物先写入临时目录再整体替换提交，清单记录全局版本号、配置哈希、张量包指纹、已完成迭代轮次与各阶段产物版本，启动时以版本号与配置哈希判定是否续跑，不一致输出 E_SNAPSHOT_STALE 并回到全量重建；收到可处理退出信号时完成当前轮产物落盘后以整数退出码 0 退出；以独立注入配置施加非有限缩放因子、累加溢出、张量包截断与快照版本被篡改等故障并写入注入编号，单块对失败记录块对标识、阶段名、业务码与异常类型后继续其余块对，报告须含每查询块的位图摘要、热块表、预算消耗、复用与重算清单及失败清单。
