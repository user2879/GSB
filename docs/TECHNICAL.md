# 技术说明

## 分层与数据流

1. `SceneLoader` 先完成全部结构和语义校验，之后才允许任何状态或记录写入。
2. `RecordLoader` 保留原始 JSON 节点；`RecordNormalizer` 按版本把 v1/v2/v3 映射为统一模型。
3. v1 只按几何快照摘要解析对象。候选数为 0、大于 1，或唯一候选的 `proxyNumber` 与记录不一致，都返回 `E_IDENT`，并报告候选。
4. v2/v3 只按 `stableId` 绑定；若记录同时携带 `proxyNumber` 或 `layerId`，它们必须与稳定标识解析结果一致。
5. `PickEngine` 用相机基向量构造世界空间单位射线。Möller–Trumbore 与每个三角形求交；同代理取最近面，跨代理按最近距离选择，距离并列时按稳定标识排序。
6. `EditorSession` 维护当前位姿和选中集。拖动平面通过初始命中点且法线为相机前向；鼠标射线与该平面的差值应用到所有选中代理。撤销保存完整位姿、选中集和视口快照。
7. `ReplayService` 对每条归一记录检查面、点、法线、对象、屏幕距离和图层字段，然后用记录中的视口/缩放/平移重投射并再次求交。桌面重放会传入当前编辑器位姿快照，因此“当前离线场景”包含拖动后的代理位置；CLI 默认使用场景文件中的位姿。
8. `PickRecordStore` 在写出前读取已有文件的版本和原始字节摘要；旧版本先原子归档，再以同目录临时文件整体替换目标文件。
9. `ChunkJournal` 每块写入 `results + metadata + chunkDigest + versionId`，重放和拾取脚本都只复用同时通过版本、结构、块范围和摘要校验的块。

## 并发与内存

`BoundedParallel` 按任务键（代理 `stableId` 或记录序号）排序，以 `SemaphoreSlim` 限制并发。任何任务在启动前必须先获得预算租约；内存预算队列严格 FIFO，所以较大代理不会因较小代理插队而长期饥饿。每个代理的预算估计包含三角形缓冲、记录文本和固定开销。

任务发生非取消异常时，调度器取消其余任务并返回排序最靠前的真实错误；健康任务被动取消不会覆盖首要错误。最终对象选择仍使用独立的确定性归并，因此并行和串行结果逐字段一致。

## 原子性

- 记录文件：同目录临时文件 → `Flush(true)` → 同卷整体替换。旧文件在新文件可替换之前一直保留。
- 旧版本归档：先原样复制到 `archive/<name>.vN.<UTC>.json`，再替换当前文件。
- 块状态：每个 `chunk-NNNNNN.json` 单独原子写入；从不改写已完成块。
- 中断：终止信号只在块完成并持久化后观察。CLI 写出 `interrupt.json`（含 `exitCode: 130`），不写完成报告。

## 确定性摘要

规范化 JSON 对对象属性按 ordinal 排序、数组保持顺序、数字统一按 invariant `double` 的 round-trip 形式输出（`-0` 规范为 `0`）。这使“内存对象 → 写盘 → 再读取”后的摘要保持一致。

- 几何快照摘要：局部 `verticesMeters + indices`。
- 场景摘要：单位、相机、视口、图层、代理标识、局部几何摘要、位姿和过滤字段。
- 版本标识：`sceneDigest + record/script collection digest + operation` 的 SHA-256。
- 块摘要：`results + metadata` 的规范化 SHA-256。

## 错误码

| 代码 | 语义 |
| --- | --- |
| `E_JSON` | JSON 语法错误或不可规范化标量 |
| `E_SCHEMA` | 缺字段、类型/范围错误、文件不可读 |
| `E_GEOMETRY` | 顶点非有限、索引越界、退化/无效几何字段 |
| `E_LAYER` | 图层字段缺失、重复或引用不存在图层 |
| `E_VERSION` | 未知场景/文件/记录/脚本版本 |
| `E_UNIT` | 单位声明与实际坐标字段不一致 |
| `E_IDENT` | 标识冲突、稳定标识冲突、摘要无匹配或摘要歧义 |
| `E_REPLAY` | 历史记录无法在当前离线场景复现 |
| `E_WRITE` | 记录文件原子写出失败 |
| `E_STATE` | 块状态或中断标记写出失败 |
| `E_RESOURCE` | 并发/内存配置无效，或单任务超过预算 |
| `E_CANCELLED` | 调用方在块边界取消 |
| `E_INTERNAL` | 未预期内部错误 |

## 已知边界

- 桌面运行验证需要 Windows 图形会话；当前 Linux 会话只能验证交叉编译和全部无界面核心行为。
- 框选使用代理投影顶点的屏幕包围盒与选框相交，属于可视化工作台常用的近似框选，不使用逐像素模板缓冲。
- `screenDistanceMeters` 是相机沿单位射线的世界距离，不是 2D 像素距离。
- 规范化数字按双精度处理；本工作台坐标和索引规模远低于该精度边界。
