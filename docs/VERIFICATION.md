# 实际验证结果

验证环境：Linux 容器内 Python 3.11（代码仅用标准库 + NumPy，Windows 上
Python 3.10+ 行为一致），NumPy 2.4.6、pytest 9.2.0，纯 CPU。

## 复现步骤（Windows）

```bat
py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python -m pytest
examples\run_example.bat
```

POSIX 等价：`bash examples/run_example.sh`。

## 验收项与实测结果

| 验收项 | 实测结果 |
| --- | --- |
| 观测集逐字节复现 | 256×256 两次生成 6 个产物文件内容哈希完全一致（`True`） |
| 观测口径 | 观测栈 (12,256,256) `<f4` 小端；真值法向/反照率 float64；光源 L2 单位化范数=1 |
| PS 求解精度（256） | 法向夹角均值 0.501°、最大 13.63°；反照率绝对偏差均值 1.7e-4、最大 0.00996 |
| 病态判定 | 256 全图条件数最大 1.357，阈值 30，病态像素 0；阈值压到 1 时全像素正确标记 |
| 解析梯度核对 | 有限差分最大绝对误差 9.7e-14（容差 1e-6），法向三分量与反照率全部 PASS |
| 增量/全量一致 | 正常路径全部瓦片核对通过；注入缓存污染时正确抛 `E_RENDER_DIVERGE` 并定位首瓦片 |
| 冲突定位 | 人为扰动下首个冲突像素、行优先排序、梯度方向夹角均正确；无冲突时不误报 |
| 确定性哈希 | 两次独立运行工作区目录清单哈希完全相同 |
| 强制终止恢复 | 第 3 轮崩溃后续写，与未中断基线的目录清单哈希同为 `f4200b9137d3…557ca48e`（含 status.json） |
| 异常分类 | `E_NONFINITE_ALBEDO`/`E_ZERO_LIGHT`/`E_DEGENERATE_VIEWS`/`E_VIEW_SKIPPED` 均带像素或视点诊断、退出码 1 |
| 原子性 | 崩溃后无残留 `.tmp`；未提交产物不被恢复逻辑承认 |

## 自动化测试

`python -m pytest` 共 34 个用例全部通过，覆盖：

* `test_generator.py`：形状/dtype、逐字节复现、口径清单、提交标记；
* `test_photometric.py`：真值恢复、病态标记与误差区间、退化/非有限/零光源、确定性；
* `test_differentiable.py`：有限差分梯度、双参数覆盖、增量/全量、分歧定位、瓦片顺序；
* `test_conflict.py`：法向/反照率冲突、确定性排序、不靠整体损失判定；
* `test_pipeline.py`：原子产物、内容哈希、崩溃恢复逐字节一致、临时文件清理、两种收敛原因；
* `test_faults.py`：注入配置 JSON 往返、副本隔离、视点跳过分类；
* `test_stage_conflict_integration.py`：集成层面的真实冲突填充；
* `test_cli.py`：生成/运行/梯度核对/崩溃恢复/病态注入的端到端返回码契约。

## 性能（256×256，12 视点，CPU）

* 观测生成：约 0.5 秒；
* 单次 PS 全图求解（8 轮 IRLS，3×3 对称阵特征值分解）：约 3.0 秒；
* 8 轮完整交替优化（每轮 PS 与 DR 各自独立求解，含渲染/核对/持久化）：约 16 秒；
* 16 样本有限差分梯度核对：约 8 秒。

## 已知边界

* 个别低反照率、高镜面占比像素的法向误差尾部约 13–17°，属前向模型在
  弱漫反射信号下的固有不适定性，误差区间与残差已逐像素输出；
* 模型采用正交相机与共享像素网格的简化多视点设定，位姿以旋转矩阵表达，
  不含透视畸变与子像素配准。
