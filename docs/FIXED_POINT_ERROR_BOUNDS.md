# 定点量化口径与误差界说明

## 1. 口径定义

会话缩放因子只允许 `k ∈ {0,1,2,3}`，对应 `s = 10^k ∈ {1,10,100,1000}`。

| 量 | 原始整数单位 | 量化公式 | 一个 tick 的含义 |
| --- | --- | --- | --- |
| 耗时代表值 | 微秒 | `q(x)=min(2^31-1, x//s)` | `s` 微秒 |
| 扫描行数 | 行 | 同上 | `s` 行 |
| 预期增益 | 基点 bps | 同上 | `s` bps |

- 乘除全部使用整数运算；截断方向固定为**向零向下取整**（非负输入即 floor）。
- 溢出不回绕，统一**饱和钳位**到 `SATURATION = 2^31-1`，并累计
  `Quantizer.saturated_count`。
- 反量化上界：`x` 与 `s*q(x)` 的单记录误差满足
  `0 ≤ x - s*q(x) ≤ s-1`。

## 2. 三级误差界

### 2.1 单记录量化误差

任意非负原始值 `x`：

```
0 ≤ x - s*(x//s) ≤ s-1   （原始单位）
```

### 2.2 逐查询比较判定误差界

比较两条定点值 `q(a)`、`q(b)` 时，两侧截断损失叠加：

```
B_quant = 2*(s-1)
B_total = B_quant + B_caliber + B_period
```

- `B_caliber`（代数口径差异）
  - 耗时：参与来源口径完全一致时为 0；否则取该查询全部归一记录
    耗时代表值的极差 `max-min`（微秒），覆盖任意 p50/p95/p99/avg/max 分歧。
  - 行数：库侧直接汇总扫描行，app/slow 历史版本可能补齐 0；混合上报时
    取最大-最小行数，否则为 0。
- `B_period`（采样周期差异）
  - 耗时：`1000 * (max(period_ms)-min(period_ms))` 微秒。
  - 行数：采样周期不影响行计数，恒为 0。

判定规则：`|q(a)-q(b)| ≤ max(floor(B_total/s), 1)` 即不可区分。

### 2.3 来源级聚合误差上界

对某来源参与的全部查询取各项之和（误差只增不减，构成保守上界）：

```
E_source = Σ_query (B_quant + B_caliber + B_period)
```

实现见 `quantization.aggregate_source_errors`，三段贡献分别可加。

## 3. 样本上的实测数值（k=1，s=10）

来源周期范围 1000ms~15000ms，因此耗时 `B_period=14,000,000` 微秒；
`B_quant=2*(10-1)=18`。

| 指标/查询 | 量化截断 | 口径差异 | 周期差异 | 合计原始 | 合计 ticks | 主导段 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| latency q101 | 18 | 100,893 | 14,000,000 | 14,100,911 | 1,410,091 | sampling_period |
| latency q102 | 18 | 106,000 | 14,000,000 | 14,106,018 | 1,410,601 | sampling_period |
| latency q103 | 18 | 111,761 | 14,000,000 | 14,111,779 | 1,411,177 | sampling_period |
| rows q101 | 18 | 87,890 | 0 | 87,908 | 8,790 | caliber |
| rows q102 | 18 | 129,878 | 0 | 129,896 | 12,989 | caliber |
| rows q103 | 18 | 170,110 | 0 | 170,128 | 17,012 | caliber |

结论：本样本耗时误差由采样周期差异主导，行数误差由口径差异主导；
量化截断始终是最小段，说明误差可归因且未被表示精度掩盖。

## 4. 不可区分决胜

候选间定点耗时差或增益差落在上述界内时：

1. 先按候选标识字典序；
2. 再按目标来源中最小的来源类型偏置序；
3. 结论显式标注 `error_affected=True` 并记录说明。

成因占比在会话层面给出三类比例：`error_indistinguishable`、
`caliber_conflict`、`high_rejected_evidence`（被否证据占比 ≥ 0.5）。
